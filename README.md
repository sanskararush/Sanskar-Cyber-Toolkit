# 🛡️ Sanskar Cyber Toolkit v3.0

An all-in-one Python-based ethical hacking & reconnaissance toolkit built for Linux and Termux.

## ✨ Features
1. **Password Strength Checker** – Analyzes password complexity and suggests improvements.
2. **Network Port Scanner** – Scans common open ports on authorized targets.
3. **Website Security Header Scanner** – Audits HTTP security headers (HSTS, CSP, X-Frame-Options, etc.).
4. **Cryptography & Hash Generator** – Generates MD5, SHA-256 hashes, and encodes/decodes Base64.
5. **DNS & IP Lookup** – Resolves domain names to IP addresses.

## 🚀 Installation & Usage
```bash
git clone https://github.com
cd Sanskar-Cyber-Toolkit
python3 sanskar_toolkit.py
```
